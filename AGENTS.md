# Working with Agentrix code and skills

Agentrix contains independent developer tools, templates and reusable agent skills. Contributors and coding agents should follow these guidelines when changing the repository:

1. Choose the tool or template affected by the task. Read its README and tests before making changes.
2. When working with a reusable skill, use [SKILL_ROUTER.md](SKILL_ROUTER.md) to find the relevant instructions.
3. Keep changes focused on a real issue or requested improvement. Avoid unrelated changes.
4. Run the relevant tests and describe what was actually verified. Be clear about any untested behavior.
5. Do not add dependencies, network access or data collection without a clear reason and documentation.
6. Never commit credentials, personal information or confidential customer data.
7. Write documentation for the person who will use the product: explain the problem, show an example, and state important limitations.

These guidelines apply to changes made in this repository. Follow [CONTRIBUTING.md](CONTRIBUTING.md) for contribution details.
