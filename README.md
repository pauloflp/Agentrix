# Paulo GPT — AI Production System

Coleção de skills operacionais para criação, pesquisa, desenvolvimento e controle de qualidade.

As skills deste repositório **não são automaticamente instaladas no ChatGPT**. Cada agente deve carregar explicitamente o arquivo `SKILL.md` relevante e cumprir seus critérios.

Não publique credenciais ou dados de clientes neste repositório público.
