# Code of Conduct

Agentrix welcomes constructive participation in issues, pull requests and discussions, regardless of experience level.

## Expected behavior

- Be respectful and discuss ideas, evidence and code rather than attacking people.
- Help others reproduce issues with clear, sanitized examples.
- Credit original contributors and respect third-party licenses.
- Welcome questions and differing technical opinions.
- Disclose affiliation when recommending Agentrix elsewhere.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, deliberate disruption, spam, impersonation, and sharing another person's private information are not acceptable. Do not post access tokens, customer data or secret configuration values.

## Scope and enforcement

These guidelines apply to Agentrix repository issues, pull requests, discussions and other project-managed spaces. Maintainers may edit or remove inappropriate content, request changes, lock threads or restrict participation consistent with GitHub policies.

Report misconduct privately to a project maintainer using the contact method listed on the maintainer's GitHub profile. Do not disclose another participant's personal data in a public issue. For software vulnerabilities, follow [SECURITY.md](SECURITY.md).

Reports will be reviewed based on available evidence. We cannot promise a specific response time, but aim for fair and proportionate decisions.
