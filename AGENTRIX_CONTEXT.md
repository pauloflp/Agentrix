# Agentrix Project Context (Public)

_Last reviewed: 2026-10-22. Public, version-controlled project briefing for new agents and Work sessions._

## Identity and positioning
- **Official name:** Agentrix (not Argentrix, Paulo GPT, or Paulo-gpt).
- **Canonical repository:** https://github.com/pauloflp/Agentrix
- **Instagram:** https://www.instagram.com/agentrix.tools/
- **Purpose:** Research, build, validate, and distribute useful microproducts for developers, designers, web designers, AI builders, marketing teams and digital creators.
- **Geography / language:** International. English-first marketing and documentation; Portuguese, Spanish or other languages when grounded in audience demand.
- **Brand status:** Premium identity, logo, guidelines, media kit and social assets are being developed separately in ChatGPT Work. Avoid treating provisional colors or graphics as approved final assets.

## Current public products
- **15 agent skills:** `skills/` and `skills/index.json` with guidance in `SKILL_ROUTER.md`. These are publicly accessible instructions for compatible agents, NOT built-in capabilities automatically installed into ChatGPT.
- **Agentrix Env Contract:** `products/agentrix-env-contract/`, a small free Node.js key comparison utility, with README, tests and MIT license. Consult the actual source before making claims.

## Catalog rules
- Research real, specific problems before writing code or graphics; document evidence and competing alternatives.
- Publish useful and differentiated products, not volume for its own sake.
- Product categories: development, design, web design, marketing, SEO, analytics, accessibility, AI agent workflows, motion and creative utilities.
- For free releases: include clear README, examples, limitations, tests or honest verification status, and appropriate license.
- Never assert downloads, revenue, testimonials or product functionality without evidence.
- Prefer human-readable search titles and naturally written keywords over SEO stuffing.
- Use `products/<slug>/` for microproducts; keep existing assets intact.

## Distribution
- GitHub is the source of truth for technical releases and public documentation.
- Instagram @agentrix.tools is a discovery and demonstration channel; posts, stories, Reels and carousels should demonstrate actual products. No posting or profile changes implied merely by modifying this file.
- Links should always point to the canonical GitHub URL.
- Product visuals and marketing must be based on verified features.

## Commercial transparency
- The 15-skill collection is contemplated as the initial paid *convenience/packaging/documentation* offer. The underlying skill files are already public; do not claim exclusivity.
- Do not present any checkout as live without verifying payment activation and delivery.
- No customer data, private financials, tokens, bank details, credentials, internal API IDs or confidential operational reports should go in this public repository.

## For new agents and Work sessions
1. Read this page, `AGENTS.md`, `SKILL_ROUTER.md`, `README.md` and `skills/index.json`.
2. Read the exact files of any product being described or changed.
3. Confirm repository name, connected app permissions and payment status at execution time.
4. Use the applicable skills as *reference procedures*, not as an assumption that a runtime has native plugins.
5. Verify output artifacts and state what was actually published, tested or blocked.

## Context architecture
This document is **public product memory only**. Private operational decisions, account status, analytics and publication approvals belong in a private workspace (e.g. connected Notion). The context file improves retrieval between sessions; it does **not** expand a language model's context window or guarantee automatic loading.
