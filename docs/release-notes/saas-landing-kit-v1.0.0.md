# SaaS Landing Kit 1.0 | Two free editable software landing page templates

**Starting a product page from a blank screen takes time.**

## Who this is for
People who need a website for a new software idea.

## What you can do
Includes two responsive HTML/CSS/JavaScript landing page designs: Atlas Analytics and Fieldnote CRM. Edit the example copy, imagery and links before publishing.

## Get started
[Read the instructions and download the free ZIP](https://github.com/pauloflp/Agentrix/tree/main/premium/agentrix-saas-landing-kit/AGENTRIX_SaaS_Landing_Kit_FREE_v1.0.zip). No checkout, account or password is required.

## Important to know
These are front-end templates, not functioning analytics or CRM software. Use the license included with the kit.
