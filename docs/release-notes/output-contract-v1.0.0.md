# Output Contract 1.0.0 | Check AI agent JSON outputs for missing fields

**An agent returns valid JSON, but fields required by the next step are missing or have the wrong type.**

## Who this is for
People building automated workflows around structured JSON outputs.

## What you can do
Checks the JSON output against an explicitly defined, limited contract and reports which fields do not match.

## Get started
[Open this free tool's page](https://github.com/pauloflp/Agentrix/blob/main/products/agentrix-output-contract/README.md) to follow a real example. It runs locally and does not require a subscription or online account. The source is MIT-licensed.

## Important to know
Supports a documented subset of JSON Schema; it's not a complete JSON Schema implementation.
