# JSON Diff 0.1.0 | Compare two JSON files and see what changed

**A JSON file changed and it's difficult to spot which fields were added, removed or modified.**

## Who this is for
People troubleshooting configuration and structured-data changes.

## What you can do
Compares two JSON files locally and identifies changed paths.

## Get started
[Open this free tool's page](https://github.com/pauloflp/Agentrix/blob/main/products/agentrix-json-diff/README.md) to follow a real example. It runs locally and does not require a subscription or online account. The source is MIT-licensed.

## Important to know
It's a comparison tool, not a data merger or validator against a schema.
