# JSONL Guard 1.0.0 | Find invalid lines in JSONL and NDJSON files

**One malformed JSON line can interrupt an import or a processing job.**

## Who this is for
People checking log exports, datasets or automation files.

## What you can do
Checks each line and reports where a problem occurred without printing the original records.

## Get started
[Open this free tool's page](https://github.com/pauloflp/Agentrix/blob/main/products/agentrix-jsonl-guard/README.md) to follow a real example. It runs locally and does not require a subscription or online account. The source is MIT-licensed.

## Important to know
Checks formatting and optional object-only rules, not the meaning or quality of the data.
