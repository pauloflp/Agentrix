# Product-feed duplicate detection joins the free catalog

[Product Feed GTIN Duplicate Check 0.1.0](https://github.com/pauloflp/Agentrix/releases/tag/product-feed-gtin-duplicate-check-v0.1.0) helps catalog operators find one GTIN assigned to several SKUs before import.

The free MIT-licensed Python tool accepts a local `sku,gtin` CSV and returns sorted duplicate groups as JSON. The synthetic example shows a shared GTIN across three SKUs. Review those assignments before changing catalog records.

[Download the ZIP](https://github.com/pauloflp/Agentrix/releases/download/product-feed-gtin-duplicate-check-v0.1.0/product-feed-gtin-duplicate-check-v0.1.0.zip) for the CLI, example, documentation, license and 30 tests. Python 3.10 or later is required.
