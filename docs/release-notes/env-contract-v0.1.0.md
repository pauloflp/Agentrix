# Env Contract 0.1.0 | Find missing environment variables before deployment

**An application runs locally but fails after deployment because an expected setting is absent.**

## Who this is for
Developers who maintain app configuration across environments.

## What you can do
Compares environment variable names against the expected list without printing secret values.

## Get started
[Open this free tool's page](https://github.com/pauloflp/Agentrix/blob/main/products/agentrix-env-contract/README.md) to follow a real example. It runs locally and does not require a subscription or online account. The source is MIT-licensed.

## Important to know
Checks names only, not whether secrets or their values are correct.
