# Data Import Studio 1.0.0 | Match CSV columns and separate invalid rows

**The receiving system expects different column names and valid values.**

## Who this is for
People preparing contacts or spreadsheet exports for another application.

## What you can do
Opens CSV files in a local browser interface, matches fields and exports valid and error rows separately.

## Get started
[Open this free tool's page](https://github.com/pauloflp/Agentrix/blob/main/products/agentrix-data-import-studio/README.md) to follow a real example. It runs locally and does not require a subscription or online account. The source is MIT-licensed.

## Important to know
It prepares files for review; it does not connect to an ERP or automatically import data.
