# Find the right Agentrix tool for your task

Looking for a **free CSV file checker**, a way to **compare JSON files**, or help finding **missing payments**? The tools below are grouped by the problems they solve, not by software jargon.

## Fix problems before you import data
- **Check a CSV for missing columns or broken quotes:** [CSV Guard](../products/agentrix-csv-guard/README.md). Useful when a spreadsheet export won't import cleanly.
- **Match CSV columns to the fields another system expects:** [Data Import Studio](../products/agentrix-data-import-studio/README.md). Prepare valid and invalid rows separately in a browser.
- **Find malformed records in JSONL / NDJSON logs:** [JSONL Guard](../products/agentrix-jsonl-guard/README.md). Shows problem line numbers without exposing record values.

## Find configuration and workflow mistakes
- **Compare two JSON files to see which settings changed:** [JSON Diff](../products/agentrix-json-diff/README.md).
- **Find missing environment variable names before deployment:** [Env Contract](../products/agentrix-env-contract/README.md). It does not print secrets.
- **Check whether an agent's JSON response has required fields:** [Output Contract](../products/agentrix-output-contract/README.md). Supports a documented, limited contract.
- **Check whether files you're about to commit may be sensitive:** [Staged File Guard](../products/agentrix-staged-file-guard/README.md). Checks file paths, not file contents.
- **Find repeated or unsuccessful webhook attempts in exported logs:** [Webhook Delivery Inspector](../products/agentrix-webhook-delivery-inspector/README.md). Does not contact live endpoints.

## Check marketing links and payments
- **Find missing UTM tags in a list of campaign URLs:** [UTM Audit](../products/agentrix-utm-audit/README.md), a free local checker.
- **Check many advertising links and export an audit report:** [Campaign QA Pro](../premium/agentrix-campaign-qa/README.md), a paid tool.
- **Compare expected payments against received amounts:** [Revenue Reconcile](../premium/revenue-tools/reconcile.md), a paid local tool.
- **Review subscription revenue and unpaid invoices:** [Revenue Pulse](../premium/revenue-tools/pulse.md), a paid local tool.

## Create a landing page for a software product
- **Need a starting design for a software landing page?** [SaaS Landing Kit](../premium/agentrix-saas-landing-kit/README.md) includes two free editable front-end templates. It is not a live SaaS platform.

## Frequently asked questions

### Can I check a CSV file before uploading it to an ERP?
Yes. CSV Guard identifies structural problems; Data Import Studio helps map fields and separate rows to review. Neither connects automatically to an ERP.

### How do I find which line of a JSONL file is invalid?
JSONL Guard checks newline-delimited JSON files and reports problem line numbers.

### Can I check whether an AI agent returned the right JSON fields?
Output Contract validates a JSON document against a limited, explicit contract. It does not evaluate whether an answer is semantically correct.

### Can Agentrix track a payment or webhook in real time?
No. The financial tools work on exported CSV data and Webhook Delivery Inspector analyzes exported logs. They do not connect directly to live services.

### Are all Agentrix tools free?
No. The nine developer microtools linked above are free under MIT. Campaign QA Pro, Revenue Reconcile and Revenue Pulse are separate paid products. The SaaS Landing Kit is a free template bundle under its own license.
